M2U51 Akıllı Kale Laboratuvarı

Bu laboratuvar çalışmasında, M2U51 mikrodenetleyicisi (MCU) ile nasıl akıllı bir sistem kuracağınızı öğreneceksiniz. Sistemimiz sıcaklığı I2C üzerinden okur ve buna göre PWM Nefes Alan LED hızını değiştirir. Çevre dostu gömülü sistem tasarımı gereği, CPU iki okuma işlemi arasında ultra düşük güç moduna geçer.

Temel Özellikler

Özellik Açıklama
Sıcaklık Sensörü Her saniye I2C üzerinden NCT7712Y değerini okur (cihaz adresi 0x48).
Nefes Alan LED Timer0 PWM birimi PB5 LED'ini sürerek görev döngüsünü (duty cycle) %20 ile %100 arasında değiştirir.
Akıllı Bağlantı Sıcaklık > 27°C ise hızlı (döngü başına 350ms); ≤ 27°C ise yavaş (döngü başına 4.2s) çalışır.
Düşük Güç İşlem beklerken NPD1 derin uyku moduna geçer. CPU kullanımı %0.1'in altına iner.

Çevre Birimi Dağılımı

Çevre Birimi Kullanım Amacı
Timer1 (LIRC) Otomatik I2C işlemleri için 1Hz'lik periyodik tetikleyici sağlar.
Timer0 (LIRC) LED nefes alma efekti için 100Hz PWM çıkışı ve kesme (interrupt) güncellemeleri sunar.
I2C0 Sensör verilerini tamamen otomatik okumak için Master Otomatik Çalışma modunu kullanır.
PDMA0 Giden veriler (TX) için CH0, gelen veriler (RX) için CH1 kanalını kullanır (topla-dağıt). İşlemciye sıfır yük bindirir.
UART0 Sıcaklık ve sistem durumunu 115200 baud hızında ekrana yazdırır.

💡 Öne Çıkan Tasarım Detayları

  • Otomatik I2C Okuma: Timer1, I2C Otomatik İşlemini tetikler → veriler PDMA ile taşınır → CPU yalnızca işlem tamamen bittiğinde uyanır.
  • Kusursuz Dalgalanma: PWM donanımı NPD1 uyku modunda çalışmaya devam eder. CPU, her 10ms'de bir sadece g_u32BreathDiv değerini güncellemek için yalnızca bir mikrosaniyeliğine uyanır.
  • Gelişmiş Derin Uyku: Yüksek hızlı saat olan HIRC'yi durdurur ve LIRC ile çalışır. Seri port çıktısının bozulmasını önlemek için uykudan önce UART önbelleğini tamamen boşaltır.
🧱 Adım 1 Saat Yapılandırması

Saat ve Sistem İlklendirmesi (SYS_Init)

1 Ana Sistem Saatlerini Etkinleştirme

Yüksek hızlı sistem saatini (HCLK) HIRC kaynağına bağlıyoruz. Saat dağıtım ayarlarını yapabilmek için öncelikle korumalı kaydedicilerin kilidini açıyoruz. 

/* Unlock protected registers */
SYS_UnlockReg();

/* Enable HIRC and LIRC clock sources */
CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk | CLK_PWRCTL_LIRCEN_Msk);

/* Wait for HIRC and LIRC clock ready */
CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
CLK_WaitClockReady(CLK_STATUS_LIRCSTB_Msk);

/* Set HCLK clock source to HIRC with divider 1 */
CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_HCLKDIV_HCLK(1));

/* Set PCLK0/PCLK1 to HCLK/2 */
CLK->PCLKDIV = (CLK_PCLKDIV_APB0DIV_DIV2 | CLK_PCLKDIV_APB1DIV_DIV2);

/* Update System Core Clock */
SystemCoreClockUpdate();

2 Çevre Birimi Saatlerini Atama

HIRC kapatıldığında ve sistem Güç Tasarrufu modundayken zamanlayıcılarımızın çalışmaya devam etmesi için Timer0 (Nefes Alan LED) ve Timer1 (I2C tetikleyici kaynağı) birimlerini düşük güçlü LIRC saatine bağlıyoruz. 

/* Select UART0 clock source as HIRC with divider 1 */
CLK_SetModuleClock(UART0_MODULE, CLK_CLKSEL2_UART0SEL_HIRC, CLK_CLKDIV_UART0(1));

/* Select TIMER0 clock source as LIRC (for PWM breathing LED, keeps running in power-down) */
CLK_SetModuleClock(TMR0_MODULE, CLK_CLKSEL1_TMR0SEL_LIRC, MODULE_NoMsk);

/* Select TIMER1 clock source as LIRC (for I2C auto-operation trigger, keeps running in power-down) */
CLK_SetModuleClock(TMR1_MODULE, CLK_CLKSEL1_TMR1SEL_LIRC, MODULE_NoMsk);

/* Enable peripheral clocks */
CLK_EnableModuleClock(UART0_MODULE);
CLK_EnableModuleClock(I2C0_MODULE);
CLK_EnableModuleClock(TMR0_MODULE);
CLK_EnableModuleClock(TMR1_MODULE);
CLK_EnableModuleClock(PDMA0_MODULE);
CLK_EnableModuleClock(GPA_MODULE);
CLK_EnableModuleClock(GPB_MODULE);
CLK_EnableModuleClock(GPC_MODULE);

3 GPIO Pin Eşlemeleri

UART0, I2C0 and Timer0 PWM çıkışları için çok işlevli pinleri yapılandırıyoruz. Gürültüyü önlemek ve sinyal kalitesini artırmak için I2C pinlerinde Schmitt tetikleyicilerini aktif hale getiriyoruz. 

/*---------------------------------------------------------------------------------------------------------*/
/* Init Multi-Function Pins                                                                                */
/*---------------------------------------------------------------------------------------------------------*/

/* Set PB13 as UART0_TXD (TX only, no RX pin to avoid leakage in power-down) */
SYS->GPB_MFPH = (SYS->GPB_MFPH & ~SYS_GPB_MFPH_PB13MFP_Msk) | SYS_GPB_MFPH_PB13MFP_UART0_TXD;

/* Set PC0 as I2C0_SDA, PC1 as I2C0_SCL */
SYS->GPC_MFPL = (SYS->GPC_MFPL & ~(SYS_GPC_MFPL_PC0MFP_Msk | SYS_GPC_MFPL_PC1MFP_Msk)) |
                 (SYS_GPC_MFPL_PC0MFP_I2C0_SDA | SYS_GPC_MFPL_PC1MFP_I2C0_SCL);

/* Enable Schmitt trigger on PC0 and PC1 for I2C noise immunity */
PC->SMTEN |= (GPIO_SMTEN_SMTEN0_Msk | GPIO_SMTEN_SMTEN1_Msk);

/* Set PB5 as TM0 PWM output for LED breathing effect */
SYS->GPB_MFPL = (SYS->GPB_MFPL & ~SYS_GPB_MFPL_PB5MFP_Msk) | SYS_GPB_MFPL_PB5MFP_TM0;
🧱 Adım 2 UART0 İletişimi

UART0 TX ve printf Log Çıkışını Etkinleştirme (UART0_Init)

1 Log Çıkışı için Baud Hızı Ayarı

Hata ayıklama mesajlarını seri port üzerinden görüntülemek için UART0 birimi vasıtasıyla printf() kullanıyoruz. Bu birimi 115200 bps hızında yapılandırıp kullanıma açıyoruz. 

void UART0_Init(void)
{
    /* Reset UART0 */
    SYS_ResetModule(UART0_RST);

    /* Configure UART0 and set UART0 baud rate */
    UART_Open(UART0, 115200);
}

2 Güç Tasarruflu Pin Tasarımı

Sistem derin uyku (NPD1) modundayken gereksiz akım sızıntılarını önlemek amacıyla yalnızca TX pinini (PB13) etkinleştiriyoruz; RX pinini ise boşta (floating) bırakarak enerjiden tasarruf sağlıyoruz.

🧱 Adım 3 Timer0 PWM LED

Timer0 PWM Nefes Alan LED Efektini Uygulama

Bu adımda, Timer_PWM_Init() ve TMR0_IRQHandler() kesme fonksiyonlarını kullanarak durum gösterge LED'imizi sürmek üzere Timer0 modülünü başlatıyoruz:

1 Timer0 PWM Yapılandırması

Saat ve Pin Gereksinimi Hatırlatıcısı
• Saat Kaynağı: LIRC (38.4kHz), ilk saat ayarları sırasında belirlenmiştir.
• Çıkış Pini: PB5 (TM0), GPB_MFPL eşlemesiyle tanımlanmıştır.

1.1 Timer0 birimini PWM moduna geçirin ve CH0 (PB5) çıkışını etkinleştirin:

/* Switch TIMER0 to PWM mode */
TPWM_ENABLE_PWM_MODE(TIMER0);

/* Enable PWM output on CH0 (PB5) */
TPWM_ENABLE_OUTPUT(TIMER0, TPWM_CH0);

1.2 Frekansı 100Hz olarak ayarlayın, başlangıç görev döngüsünü %0 (LED kapalı) yapın:

/* Set frequency 100Hz, 0% initial duty */
TPWM_ConfigOutputFreqAndDuty(TIMER0, 100, 0);

1.3 Görev döngüsü ölçeklendirmesi için periyot değerini okuyun (LIRC sapmalarını dengeler):

/* Read actual period count from register */
PWM_PERIOD_Value = TIMER0->PWMPERIOD + 1;

1.4 Timer0 saatini uyku modunda (NPD1) ve hata ayıklayıcı altında aktif tutun:

/* Enable Power-down engine clock */
TIMER0->CTL |= TIMER_CTL_PDCLKEN_Msk;

/* Keep PWM active in debug mode */
SYS_UnlockReg();
TIMER0->PWMCTL |= TIMER_PWMCTL_DBGTRIOFF_Msk;
SYS_LockReg();

1.5 ISR'yi her 10ms'de bir (100Hz) tetiklemek için akümülatör ve uyanma ayarlarını yapın:

/* Enable accumulator: IFACNT=0 means fire every 1 period (100 ISR/sec at 100Hz PWM) */
TPWM_EnableAcc(TIMER0, 0, TPWM_IFA_PERIOD_POINT);

/* Enable accumulator interrupt (software divider controls breathing speed) */
TPWM_EnableAccInt(TIMER0);
NVIC_EnableIRQ(TMR0_IRQn);

/* Enable TPWM interrupt wake-up so TMR0 ISR can wake CPU from NPD1 to update PWMCMPDAT */
TPWM_EnableWakeup(TIMER0);

2 TMR0_IRQHandler Kesme Servis Rutini (ISR)

Her 10ms'de bir gelen kesme sinyali g_u32BreathCnt değerini artırır. Bu sayaç g_u32BreathDiv sınırına ulaştığında, LED parlaklığını pürüzsüzce değiştirmek için bir sonraki duty cycle değerini yükler. 

void TMR0_IRQHandler(void)
{
    /* Clear wakeup flag (needed when waking from NPD1) */
    TPWM_ClearWakeupFlag(TIMER0);

    if (TIMER0->PWMAINTSTS & TIMER_PWMAINTSTS_IFAIF_Msk)
    {
        /* Clear accumulator interrupt flag */
        TIMER0->PWMAINTSTS = TIMER_PWMAINTSTS_IFAIF_Msk;

        if (++g_u32BreathCnt >= g_u32BreathDiv)
        {
            g_u32BreathCnt = 0;
            TIMER0->PWMCMPDAT = SrcArray_PWM[g_u32PWMIdx];
            g_u32PWMIdx = (g_u32PWMIdx + 1) % PWM_PDMA_LENGTH;
        }
    }
}

3 Görev Döngüsü Tablosunu (Duty Table) İlklendirme

main() fonksiyonu içerisinde, donanımın periyot sayısına göre PWM adımlarını otomatik olarak hesaplıyoruz: %20 ↔ %40 ↔ %80 ↔ %100 ↔ %80 ↔ %40 ↔ %20. 

/* Build PWM breathing duty table: 20%->40%->80%->100%->80%->40%->20% of PWM period */
SrcArray_PWM[0] = PWM_PERIOD_Value * 20 / 100;
SrcArray_PWM[1] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[2] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[3] = PWM_PERIOD_Value * 100 / 100;
SrcArray_PWM[4] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[5] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[6] = PWM_PERIOD_Value * 20 / 100;
🧱 Adım 4 I2C0 + PDMA Aktarım Bağlantısı

Otomatik I2C Veri Aktarımı

Arka planda kesintisiz çalışan otomatik bir veri taşıma hattı tasarlıyoruz: Timer1 modülü 1Hz hızında taşar → Donanım doğrudan I2C0'ı tetikler → PDMA verileri işlemci yükü olmadan aktarır.

💡 Blok Mimarisi: Bu veri hattı üç ana bileşenden oluşur: Sensöre istek göndermek için bir TX Tablosu, gelen değerleri saklamak için bir RX Tablosu ve bu döngüyü saniyede bir tetikleyen Timer1 birimi.

1 TX Scatter-Gather Tablosunu Oluşturma

TX listesi, I2C birimine [SLV+W, Reg Addr, SLV+R] komut dizisini yükler. Listenin son elemanı listenin en başına (DMA_DESC_SC_TX[0]) bağlanarak işlemcinin müdahalesine gerek kalmadan sürekli döner. 

void Build_Tx_SCTab(uint32_t u32TabNum, uint32_t u32TxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_TX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_DAR_FIX |
                                PDMA_SAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32TxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_TX[i].src    = (uint32_t)(u32StartAddr + i * u32TxSize);
        DMA_DESC_SC_TX[i].dest   = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_TX[i].offset = (uint32_t)&DMA_DESC_SC_TX[0] - SG_BASE_ADDR;
    }
}

2 RX Scatter-Gather Tablosunu Oluşturma

Toplamda 5 adet sıcaklık değeri (toplam 10 bayt) okuyoruz. Son veri tanımlayıcısını BASIC modu ve 0 ofseti ile yapılandırıyoruz. Bu sayede veri alımı bittiğinde süreç durur ve CPU'ya "Veri alma tamamlandı!" uyarısı gönderilir. 

void Build_Rx_SCTab(uint32_t u32TabNum, uint32_t u32RxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_RX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_SAR_FIX |
                                PDMA_DAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32RxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_RX[i].src    = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_RX[i].dest   = (uint32_t)(u32StartAddr + i * u32RxSize);
        DMA_DESC_SC_RX[i].offset = (uint32_t)&DMA_DESC_SC_RX[0] + 0x10 * (i + 1) - (PDMA0->SCATBA);
    }

    /* For the last entry: enable transfer-done interrupt and switch to basic mode */
    DMA_DESC_SC_RX[u32TabNum - 1].ctl = (DMA_DESC_SC_RX[u32TabNum - 1].ctl & ~(PDMA_DSCT_CTL_TBINTDIS_Msk | PDMA_DSCT_CTL_OPMODE_Msk)) |
                                        (PDMA_TBINTDIS_ENABLE | PDMA_OP_BASIC);
    DMA_DESC_SC_RX[u32TabNum - 1].offset = 0;
}

3 I2C Otomatik Tetikleme Birimini Yapılandırma

I2C Otomatik Çalışma modunu, Timer1'in saniyelik (1Hz) periyodik taşma sinyallerine bağlıyoruz. Böylece ana işlemciyi uyandırmadan arka planda tüm I2C iletişimini donanımsal olarak yürütüyoruz. 

void I2C_Trigger_Init(uint32_t u32Mode, uint32_t u32Src, uint32_t u32RxCnt, uint32_t u32TxCnt)
{
    /* Set Auto-operation Mode */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_AUTOMODE_Msk) | (u32Mode);

    /* Trigger source select */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_TGSRCSEL_Msk) | (u32Src);

    I2C0->AUTOCNT = (I2C0->AUTOCNT & ~(I2C_AUTOCNT_RXCNT_Msk | I2C_AUTOCNT_TXCNT_Msk));

    if (u32RxCnt != 0)
        I2C0->AUTOCNT |= ((u32RxCnt - 1) << I2C_AUTOCNT_RXCNT_Pos);

    if (u32TxCnt != 0)
        I2C0->AUTOCNT |= ((u32TxCnt - 1) << I2C_AUTOCNT_TXCNT_Pos);

    I2C0->AUTOCTL |= I2C_AUTOCTL_TRGEN_Msk;
}
🧱 Adım 5 Düşük Güç Entegrasyonu

Güç Tasarrufu Kontrolü ve Ana Döngü (AutoOperation_FunctionTest)

1 I2C Arabelleğini Biçimlendirme

I2C veri paketlerini, hedef sensörün adresi ve kaydedici numarası ile komut arabelleğine yerleştiriyoruz:

  • SrcArray[0] = ((g_u8DeviceAddr << 1) | 0x00) (Yazma Komutu / Write)
  • SrcArray[1] = 0x00 (Sıcaklık Değerinin Kaydedici Adresi)
  • SrcArray[2] = ((g_u8DeviceAddr << 1) | 0x01) (Okuma Komutu / Read)
for (i = 0; i < SG_TX_TAB_NUM; i++)
{
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x00);   /* SLV + W (0x00) */
    *pu8Tmp++ = 0x00;                              /* Register address */
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x01);   /* SLV + R (0x01) */
}

2 Geri Çağırma (Callback) Ataması

Veri hattı durumu geri çağırma işaretçisini doğrudan I2C_PDMA_MasterRx fonksiyonuna yönlendiriyoruz. 

/* Set I2C0 interrupt callback for master receive operation */
s_I2C0HandlerFn = (I2C_FUNC)I2C_PDMA_MasterRx;
I2C_SET_CONTROL_REG(I2C0, I2C_CTL_AA);

3 DMA Kanallarını Eşleme

Tanımladığımız kontrol tablolarını doğrudan donanımsal aktarım hatlarına bağlıyoruz:

  • CH0 (TX): Komut paketlerini kesintisiz aktarmak için dairesel listeyi çalıştırır.
  • CH1 (RX): 5 okuma paketini hafızaya alır. İşlem bittiğinde CPU'ya veri alımının bittiğini bildiren kesmeyi tetikler.
/* PDMA CH0 scatter-gather mode to write data to slave */
PDMA_TX_Init(I2C0_PDMA_TX_CH, SG_TX_TAB_NUM, SG_TX_LENGTH);

/* PDMA CH1 scatter-gather mode to receive data from slave */
PDMA_RX_Init(I2C0_PDMA_RX_CH, SG_RX_TAB_NUM, SG_RX_LENGTH);

4 Otomatik Çalışmayı Başlatma

I2C otomatik çalışma ayarlarını saniyelik Timer1 periyodik saat çıkışına bağlıyoruz. 

/* Auto operation random read mode with repeat start, triggered by TIMER1 */
I2C_Trigger_Init(I2C_RANDOM_REPEAT_STA, I2C_AUTOCTL_TRIGSEL_TMR1, SG_RX_LENGTH, SG_TX_LENGTH);

5 Derin Uyku Modunu Yapılandırma (NPD1)

Ana saatleri durdurarak işlemciyi derin uykuya geçirmek için CLK_PowerDown() komutunu çağırıyoruz. Çevre birimleri donanımsal olarak çalışmaya devam ederken CPU akımı sıfıra yakın bir düzeye çeker.

NPD1 Derin Uyku Nasıl Çalışır:
  • HIRC Durdurulur → CPU, PDMA ve UART donanımları beklemeye geçer. Enerji tüketimi muazzam oranda düşer.
  • LIRC Aktiftir → Timer0, PWM LED'ini sürmeye devam eder ve Timer1 arka planda saniyeleri sayar.
  • ★ Uyanma 1: Timer0 Akümülatörü (Her 10ms'de Bir):
    • CPU anlık olarak uyanır, TMR0_IRQHandler fonksiyonunu çalıştırır ve LED parlaklığını günceller.
    • PDMA_DONE durumunu kontrol eder. Değer hâlâ 0 ise CPU beklemeden anında derin uykuya geri döner.
  • ★ Uyanma 2: Timer1 Zaman Aşımı (Her 1s'de Bir):
    • Timer1 taşar ve işlemciyi uyandırmadan doğrudan I2C Otomatik Okuma döngüsünü başlatır.
    • I2C hattı işlemi tamamlar: START → SLA+W → REG → Repeat START → SLA+R → READ → STOP.
    • Okunan veriler PDMA birimi aracılığıyla doğrudan hafızaya (DestArray) taşınır.
    • Son veri paketi okunduğunda bir kesme tetiklenir, PDMA0_IRQHandler çalışır, PDMA_DONE = 1 yapılarak CPU sıcaklığı işlemek üzere tamamen uyandırılır.
SYS_UnlockReg();
CLK_SetPowerDownMode(CLK_PMUCTL_PDMSEL_NPD1);
CLK->PMUCTL = (CLK->PMUCTL & ~(CLK_PMUCTL_PDLDCSEL_Msk)) | CLK_PMUCTL_PDLDCSEL_ULP;

while (!PDMA_DONE)
{
    /* Clear wakeup flag */
    CLK->PMUSTS |= CLK_PMUSTS_CLRWK_Msk;

    /* Prevent UART corruption */
    UART_WAIT_TX_EMPTY(UART0);

    /* CPU & HIRC suspended here */
    CLK_PowerDown();
}
SYS_LockReg();

6 Sıcaklık Verilerini Çözümleme

Hafızaya alınan 5 sıcaklık ölçümünü (MSB ve LSB olmak üzere her biri 2 bayt) matematiksel olarak işliyoruz:

raw = (DestArray[i] << 8 | DestArray[i+1]) >> 4; (12-bit)
if (raw & 0x800) → Negative: Two's complement × -0.0625f;
else → Positive: × 0.0625f; 
for (i = 0; i < SG_RX_TAB_NUM * 2; i += 2)
{
    NCT7712Y_Data  = DestArray[i];
    NCT7712Y_Data <<= 8;
    NCT7712Y_Data |= DestArray[i + 1];
    NCT7712Y_Data >>= 4;

    if (NCT7712Y_Data & 0x800)
    {
        /* Negative conversion */
        NCT7712Y_Data = ~NCT7712Y_Data & 0x00000FFF;
        NCT7712Y_Data += 1;
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * -0.0625f);
    }
    else
    {
        /* Positive conversion */
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * 0.0625f);
    }
    printf("Current Temperature = %.4f degrees Celsius.\n", NCT7712Y_Data_F);
}

7 LED Nefes Alma Hızını Değiştirme

Ölçülen sıcaklığa göre yazılım tabanlı genel bölücü değişkenimiz olan g_u32BreathDiv değerini güncelliyoruz. Bir sonraki 10ms'lik periyodik kesme, herhangi bir duraksama yaratmadan bu değişikliği anında uygular.

  • Sıcaklık > 27°C → g_u32BreathDiv = 5 (Hızlı nefes alma: Döngü başına 350ms)
  • Sıcaklık ≤ 27°C → g_u32BreathDiv = 60 (Sakin nefes alma: Döngü başına 4.2s)
if (NCT7712Y_Data_F > 27.0f)
{
    g_u32BreathDiv = 5;    /* Fast (Div: 5) */
    printf("Fast breathing\n");
}
else
{
    g_u32BreathDiv = 60;   /* Slow (Div: 60) */
    printf("Slow breathing\n");
}
