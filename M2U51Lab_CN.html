📋 專案導言 M2U51 MCU 訓練實作藍圖

M2U51 智慧溫控呼吸城堡

這個專案是 M2U51 MCU 訓練課程的實作範例，結合兩個核心功能：I2C 溫度感測 與 PWM 呼吸燈，並依據溫度自動調整呼吸速度。系統在非資料搬移期間將大腦關閉進入極低功耗模式，實現高效率、零等待的綠色嵌入式設計。

專案核心功能

功能 項目說明
溫度量測 透過 I2C0 每秒自動讀取 NCT7712Y 溫度感測器（位址 0x48）
呼吸燈 Timer0 PWM 驅動 PB5 上的 LED，佔空比在 20% ↔ 100% 間循環變化
溫度連動 溫度 > 27°C → 呼吸加快（350ms/週期）；≤ 27°C → 呼吸放慢（4.2s/週期）
省電設計 等待期間進入 NPD1 深度省電，CPU 使用率 < 0.1%

晶片硬體周邊配置

周邊 用途
Timer1 (LIRC) 1Hz 週期觸發 I2C Auto-Operation
Timer0 (LIRC) 100Hz PWM 輸出 + 累加器中斷更新佔空比（呼吸燈）
I2C0 Master Auto-Operation 模式，自動執行 Random Read
PDMA0 CH0 = I2C TX、CH1 = I2C RX（scatter-gather），全程不需 CPU 介入
UART0 115200 baud 印出溫度與狀態訊息

💡 專案核心設計特點

  • 全自動 I2C 讀取： Timer1 觸發 → I2C Auto-Op 硬體執行匯流排時序 → PDMA 搬運資料 → 完成後中斷喚醒 CPU，期間大腦全程沉睡。
  • ISR 軟體除頻呼吸燈： Timer0 PWM 硬體輸出波形在 NPD1 狀態下不中斷，ISR 每 10ms 喚醒 CPU 更新佔空比，速度切換只改一個變數（g_u32BreathDiv），不需停止或重啟計時器。
  • NPD1 省電設計： HIRC 停止，僅靠 LIRC 維持 Timer0/Timer1 運行；UART 傳完再進 NPD1 避免亂碼；喚醒後等 HIRC 穩定再印字。
🧱 步驟一 時脈設定與初始化

時脈與初始化配置 (SYS_Init)

1 在 sys_init 開啟核心時鐘

CPU 主頻（HCLK）設定並綁定高速的 HIRC。在此處我們一併調用受保護暫存器解鎖，以便配置核心與系統時脈配額。 

/* Unlock protected registers */
SYS_UnlockReg();

/* Enable HIRC and LIRC clock sources */
CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk | CLK_PWRCTL_LIRCEN_Msk);

/* Wait for HIRC and LIRC clock ready */
CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
CLK_WaitClockReady(CLK_STATUS_LIRCSTB_Msk);

/* Set HCLK clock source to HIRC with divider 1 */
CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_HCLKDIV_HCLK(1));

/* Set PCLK0/PCLK1 to HCLK/2 */
CLK->PCLKDIV = (CLK_PCLKDIV_APB0DIV_DIV2 | CLK_PCLKDIV_APB1DIV_DIV2);

/* Update System Core Clock */
SystemCoreClockUpdate();

3 設定與開啟周邊 peripheral 的時鐘

這裡有使用到 TMR0, TMR1, UART, I2C0, PDMA0。為了讓晶片進入掉電模式（Power-Down）關閉 HIRC 時，計時器依然能背景運轉，我們把 Timer0（呼吸燈）與 Timer1（I2C 觸發源）綁定在低速且省電的 LIRC 上。 

/* Select UART0 clock source as HIRC with divider 1 */
CLK_SetModuleClock(UART0_MODULE, CLK_CLKSEL2_UART0SEL_HIRC, CLK_CLKDIV_UART0(1));

/* Select TIMER0 clock source as LIRC (for PWM breathing LED, keeps running in power-down) */
CLK_SetModuleClock(TMR0_MODULE, CLK_CLKSEL1_TMR0SEL_LIRC, MODULE_NoMsk);

/* Select TIMER1 clock source as LIRC (for I2C auto-operation trigger, keeps running in power-down) */
CLK_SetModuleClock(TMR1_MODULE, CLK_CLKSEL1_TMR1SEL_LIRC, MODULE_NoMsk);

/* Enable peripheral clocks */
CLK_EnableModuleClock(UART0_MODULE);
CLK_EnableModuleClock(I2C0_MODULE);
CLK_EnableModuleClock(TMR0_MODULE);
CLK_EnableModuleClock(TMR1_MODULE);
CLK_EnableModuleClock(PDMA0_MODULE);
CLK_EnableModuleClock(GPA_MODULE);
CLK_EnableModuleClock(GPB_MODULE);
CLK_EnableModuleClock(GPC_MODULE);

5 引腳功能設置

這裡有使用到 UART0, I2C0, Timer0 作為 PWM 輸出。引腳配置包括將 PC0/PC1 配置給 I2C0 匯流排，並加裝 Schmitt 觸發器抗干擾；以及將 PB5 對接為 Timer0 的 PWM 輸出引腳。 

/*---------------------------------------------------------------------------------------------------------*/
/* Init Multi-Function Pins                                                                                */
/*---------------------------------------------------------------------------------------------------------*/

/* Set PB13 as UART0_TXD (TX only, no RX pin to avoid leakage in power-down) */
SYS->GPB_MFPH = (SYS->GPB_MFPH & ~SYS_GPB_MFPH_PB13MFP_Msk) | SYS_GPB_MFPH_PB13MFP_UART0_TXD;

/* Set PC0 as I2C0_SDA, PC1 as I2C0_SCL */
SYS->GPC_MFPL = (SYS->GPC_MFPL & ~(SYS_GPC_MFPL_PC0MFP_Msk | SYS_GPC_MFPL_PC1MFP_Msk)) |
                 (SYS_GPC_MFPL_PC0MFP_I2C0_SDA | SYS_GPC_MFPL_PC1MFP_I2C0_SCL);

/* Enable Schmitt trigger on PC0 and PC1 for I2C noise immunity */
PC->SMTEN |= (GPIO_SMTEN_SMTEN0_Msk | GPIO_SMTEN_SMTEN1_Msk);

/* Set PB5 as TM0 PWM output for LED breathing effect */
SYS->GPB_MFPL = (SYS->GPB_MFPL & ~SYS_GPB_MFPL_PB5MFP_Msk) | SYS_GPB_MFPL_PB5MFP_TM0;
🧱 步驟二 UART0 通訊

開啟 UART0 TX，透過 printf 輸出訊息 (UART0_Init)

1 為城堡裝上除錯透視鏡並設定 Baudrate

在未來的調試擴充中，大腦隨時能使用 printf() 透過外設腳位輸出關鍵提示，免去盲目猜測內部狀態的困擾。我們在程式中首先重設 UART0，並呼叫外設函式配置工作鮑率為 115200 bps。 

void UART0_Init(void)
{
    /* Reset UART0 */
    SYS_ResetModule(UART0_RST);

    /* Configure UART0 and set UART0 baud rate */
    UART_Open(UART0, 115200);
}

2 節能低功耗硬體設計

為了避免在深度掉電模式（NPD1 Mode）下發生漏電，我們刻意僅配置了 TX 發送腳位（PB13），不使用或浮空 RX 腳位，從物理層面截斷可能引起漏電的洩流通道。同時呼叫低功耗初始化函數，排除全晶片其餘閒置腳位漏電。

🧱 步驟三 Timer0 PWM LED

完成 Timer0 PWM 呼吸燈的功能

本步驟主要由 Timer_PWM_Init()、TMR0_IRQHandler() 中斷 與 main() 中 PWM 的陣列初始化組成：

1 Timer0 PWM 模組配置 (Timer_PWM_Init)

前置時脈與引腳配置提示
• 時鐘源：LIRC (38.4kHz)，先前已在 SYS_Init 中綁定設定
• 輸出腳位：PB5 (TM0)，先前已在 SYS_Init 中完成 MFP 多功能重對映

1.1 將 Timer0 從計時器模式切換為 PWM 模式，並啟用 PWM 通道 0 輸出（對應 PB5 腳位）：

/* Switch TIMER0 to PWM mode */
TPWM_ENABLE_PWM_MODE(TIMER0);

/* Enable PWM output on CH0 (PB5) */
TPWM_ENABLE_OUTPUT(TIMER0, TPWM_CH0);

1.2 設定 PWM 頻率 100Hz，初始佔空比 0%（LED 全暗）：

/* Set frequency 100Hz, 0% initial duty */
TPWM_ConfigOutputFreqAndDuty(TIMER0, 100, 0);

1.3 讀回硬體實際計算的 period 計數值，供後續計算佔空比（因為 LIRC 頻率不精確，實際值由硬體決定）：

/* Read actual period count from register */
PWM_PERIOD_Value = TIMER0->PWMPERIOD + 1;

1.4 啟用 Power-Down Engine Clock，NPD1 時 Timer0 繼續用 LIRC 計數，PWM 波形不中斷；以及啟用 Debug 模式下不停止 PWM：

/* Enable Power-down engine clock */
TIMER0->CTL |= TIMER_CTL_PDCLKEN_Msk;

/* Keep PWM active in debug mode */
SYS_UnlockReg();
TIMER0->PWMCTL |= TIMER_PWMCTL_DBGTRIOFF_Msk;
SYS_LockReg();

1.5 啟用累加器，IFACNT=0 表示每 1 個 period 就觸發一次中斷（100Hz → 每 10ms 觸發）；觸發時機在 period 邊界，啟用累加器中斷，觸發時進入 TMR0_IRQHandler 更新佔空比，啟用 PWM 中斷喚醒功能，讓 TMR0 中斷能從 NPD1 喚醒 CPU：

/* Enable accumulator: IFACNT=0 means fire every 1 period (100 ISR/sec at 100Hz PWM) */
TPWM_EnableAcc(TIMER0, 0, TPWM_IFA_PERIOD_POINT);

/* Enable accumulator interrupt (software divider controls breathing speed) */
TPWM_EnableAccInt(TIMER0);
NVIC_EnableIRQ(TMR0_IRQn);

/* Enable TPWM interrupt wake-up so TMR0 ISR can wake CPU from NPD1 to update PWMCMPDAT */
TPWM_EnableWakeup(TIMER0);

2 TMR0_IRQHandler() 中斷服務常式

每次 10ms 中斷（100Hz 邊界點）戳入時，計數器 g_u32BreathCnt 會累加 1。一旦累積到指定的除頻閘限 g_u32BreathDiv，即清除計數並更更新為下一個亮度佔空比，完成亮暗平滑遞變. 

void TMR0_IRQHandler(void)
{
    /* Clear wakeup flag (needed when waking from NPD1) */
    TPWM_ClearWakeupFlag(TIMER0);

    if (TIMER0->PWMAINTSTS & TIMER_PWMAINTSTS_IFAIF_Msk)
    {
        /* Clear accumulator interrupt flag */
        TIMER0->PWMAINTSTS = TIMER_PWMAINTSTS_IFAIF_Msk;

        if (++g_u32BreathCnt >= g_u32BreathDiv)
        {
            g_u32BreathCnt = 0;
            TIMER0->PWMCMPDAT = SrcArray_PWM[g_u32PWMIdx];
            g_u32PWMIdx = (g_u32PWMIdx + 1) % PWM_PDMA_LENGTH;
        }
    }
}

3 main() 佔空比陣列初始化

在主程式 main() 中，基於硬體讀回的實際極值頻率 PWM_PERIOD_Value，依序寫入 20% ↔ 40% ↔ 80% ↔ 100% ↔ 80% ↔ 40% ↔ 20% 的波形資料表。 

/* Build PWM breathing duty table: 20%->40%->80%->100%->80%->40%->20% of PWM period */
SrcArray_PWM[0] = PWM_PERIOD_Value * 20 / 100;
SrcArray_PWM[1] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[2] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[3] = PWM_PERIOD_Value * 100 / 100;
SrcArray_PWM[4] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[5] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[6] = PWM_PERIOD_Value * 20 / 100;
🧱 步驟四 I2C0 + PDMA 自動物流

自動運作傳送帶 (Auto operation mode的流程設計)

建立一條完全自動化的「資料」物流傳送帶：由定時（Timeout）溢出的 Timer1 溢位 → 自動觸發 I2C0 啟動匯流排時序 → 透過 PDMA 全自動搬運溫度資料。

💡 結構化設計架構：此自動化鏈路包含三個核心設計：首先需要建立 TX Table 才可以讓 MCU 下 I2C 指令給溫度感測器，接著建立 RX Table 讓感測到的溫度資料有通道可以回傳，最後再設定由 Timer1 觸發 讓 I2C 自動執行指令。

1 TX Scatter-gather Table 建立

TX 散集任務負責把隨機讀取的寫入指令 [SLV+W, Reg Addr, SLV+R] 遞給 I2C。注意其最後的 offset 恆指向 DMA_DESC_SC_TX[0] 本身，構成一條循環鏈結串列，硬體可無限重複使用此表，完全不耗費大腦。 

void Build_Tx_SCTab(uint32_t u32TabNum, uint32_t u32TxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_TX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_DAR_FIX |
                                PDMA_SAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32TxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_TX[i].src    = (uint32_t)(u32StartAddr + i * u32TxSize);
        DMA_DESC_SC_TX[i].dest   = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_TX[i].offset = (uint32_t)&DMA_DESC_SC_TX[0] - SG_BASE_ADDR;
    }
}

2 RX Scatter-gather Table 建立

RX 散集任務需要讀回 5 組（共 10 位元組）的溫度數據。前 4 個描述節點依序指向下一個。但 最後一個節點被強制改回 BASIC 模式，且 offset 設為 0。代表資料搬運到此處即停止，並彈出中斷通知 CPU：「報告，5 組資料已全部收完！」 

void Build_Rx_SCTab(uint32_t u32TabNum, uint32_t u32RxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_RX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_SAR_FIX |
                                PDMA_DAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32RxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_RX[i].src    = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_RX[i].dest   = (uint32_t)(u32StartAddr + i * u32RxSize);
        DMA_DESC_SC_RX[i].offset = (uint32_t)&DMA_DESC_SC_RX[0] + 0x10 * (i + 1) - (PDMA0->SCATBA);
    }

    /* For the last entry: enable transfer-done interrupt and switch to basic mode */
    DMA_DESC_SC_RX[u32TabNum - 1].ctl = (DMA_DESC_SC_RX[u32TabNum - 1].ctl & ~(PDMA_DSCT_CTL_TBINTDIS_Msk | PDMA_DSCT_CTL_OPMODE_Msk)) |
                                        (PDMA_TBINTDIS_ENABLE | PDMA_OP_BASIC);
    DMA_DESC_SC_RX[u32TabNum - 1].offset = 0;
}

3 設定 I2C 的 Auto Operation 模式與定時溢動觸發

最後，設定 I2C 的 Auto Operation 模式，並與定時 1Hz 溢出的 Timer1 連動。當 Timer1 計時溢出時，會自動觸發 I2C0 的 Auto-Op 機械，進行讀寫資料交互，實現完全不需要 CPU 介入的背景資料鏈路。 

void I2C_Trigger_Init(uint32_t u32Mode, uint32_t u32Src, uint32_t u32RxCnt, uint32_t u32TxCnt)
{
    /* Set Auto-operation Mode */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_AUTOMODE_Msk) | (u32Mode);

    /* Trigger source select */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_TGSRCSEL_Msk) | (u32Src);

    I2C0->AUTOCNT = (I2C0->AUTOCNT & ~(I2C_AUTOCNT_RXCNT_Msk | I2C_AUTOCNT_TXCNT_Msk));

    if (u32RxCnt != 0)
        I2C0->AUTOCNT |= ((u32RxCnt - 1) << I2C_AUTOCNT_RXCNT_Pos);

    if (u32TxCnt != 0)
        I2C0->AUTOCNT |= ((u32TxCnt - 1) << I2C_AUTOCNT_TXCNT_Pos);

    I2C0->AUTOCTL |= I2C_AUTOCTL_TRGEN_Msk;
}
🧱 步驟五 主迴圈與低功耗整合

主迴圈：將所有組件串接並且完成低功耗整合 (AutoOperation_FunctionTest)

1 準備 I2C 封包資料

將欲發送的寫入封包封裝入寫入暫存陣列中，以準備呼叫 I2C 讀寫調度。

  • SrcArray[0] = ((g_u8DeviceAddr << 1) | 0x00) (SLV + W)
  • SrcArray[1] = 0x00 (溫度暫存器位址)
  • SrcArray[2] = ((g_u8DeviceAddr << 1) | 0x01) (SLV + R)
for (i = 0; i < SG_TX_TAB_NUM; i++)
{
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x00);   /* SLV + W (0x00) */
    *pu8Tmp++ = 0x00;                              /* Register address */
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x01);   /* SLV + R (0x01) */
}

2 設定 I2C 回調函式 (Callback)

設定 I2C0 的中斷回調函式為 I2C_PDMA_MasterRx 處理匯流排狀態。 

/* Set I2C0 interrupt callback for master receive operation */
s_I2C0HandlerFn = (I2C_FUNC)I2C_PDMA_MasterRx;
I2C_SET_CONTROL_REG(I2C0, I2C_CTL_AA);

3 配置 PDMA 收發通道

將 TX 與 RX 兩個 Scatter-Gather 鏈結通道與 I2C0 搬運端點對置：

  • CH0 (TX)：scatter-gather, 1 descriptor。搬移 SrcArray[0..2] → I2C0->DAT (3 bytes，循環環狀鏈結)
  • CH1 (RX)：scatter-gather, 5 descriptors。每個搬移 I2C0->DAT → DestArray (2 bytes)；最後一個 descriptor 設為 BASIC 模式 並開啟 transfer-done 完成中斷。
/* PDMA CH0 scatter-gather mode to write data to slave */
PDMA_TX_Init(I2C0_PDMA_TX_CH, SG_TX_TAB_NUM, SG_TX_LENGTH);

/* PDMA CH1 scatter-gather mode to receive data from slave */
PDMA_RX_Init(I2C0_PDMA_RX_CH, SG_RX_TAB_NUM, SG_RX_LENGTH);

4 配置 I2C Auto-Operation

將模式設定為 Random Read + Repeat Start，並將自動發動源連線至 Timer1 (1Hz 定時溢位)，指定 TX 長度為 3、RX 長度為 2 位元組。 

/* Auto operation random read mode with repeat start, triggered by TIMER1 */
I2C_Trigger_Init(I2C_RANDOM_REPEAT_STA, I2C_AUTOCTL_TRIGSEL_TMR1, SG_RX_LENGTH, SG_TX_LENGTH);

5 進入 NPD1 省電等待

CPU 進入極致低功耗的 NPD1 掉電模式。當 CPU 執行到 CLK_PowerDown() 時，高速時脈關閉，主程式暫停。

NPD1 運作核心機理：
  • HIRC 停止 → CPU、PDMA 與 UART 停止，耗電極小。
  • LIRC 繼續 → Timer0 PWM 波形維持輸出（LED繼續亮暗變化），Timer1 繼續定時計數。
  • ★ 喚醒源 ①: TMR0 累加器中斷 (每 10ms)：
    • 喚醒大腦進入 TMR0_IRQHandler 中斷常式改寫暫存器換亮度佔空比。
    • 回來檢查 PDMA_DONE 旗標，由於仍為 0，大腦更新完隨即又跌回休眠睡眠狀態.
  • ★ 喚醒源 ②: Timer1 timeout (每 1 秒)：
    • 自動溢出不驚動大腦，硬體直接觸發 I2C0 Auto-Op 開始讀取。
    • I2C 匯流排自動跑完：START → SLV+W → REG → REPEAT START → SLV+R → 讀回 → STOP。
    • PDMA CH0 自動搬移 TX，PDMA CH1 自動搬回 RX 到 DestArray 中。
    • RX 描述表最後一筆搬完後，觸發完成中斷進入 PDMA0_IRQHandler 將 PDMA_DONE = 1，CPU 被徹底喚醒跳出 while 迴圈。
SYS_UnlockReg();
CLK_SetPowerDownMode(CLK_PMUCTL_PDMSEL_NPD1);
CLK->PMUCTL = (CLK->PMUCTL & ~(CLK_PMUCTL_PDLDCSEL_Msk)) | CLK_PMUCTL_PDLDCSEL_ULP;

while (!PDMA_DONE)
{
    /* 清除喚醒旗標 */
    CLK->PMUSTS |= CLK_PMUSTS_CLRWK_Msk;

    /* UART_WAIT_TX_EMPTY ← 防止 UART 亂碼 */
    UART_WAIT_TX_EMPTY(UART0);

    /* CLK_PowerDown() ← CPU+HIRC 停止 */
    CLK_PowerDown();
}
SYS_LockReg();

6 解碼 NCT7712Y 溫度資料

收回來的 5 筆溫度資料 (每筆 2 位元組，MSB 與 LSB)。解碼公式如下：

raw = (DestArray[i] << 8 | DestArray[i+1]) >> 4; (12-bit)
if (raw & 0x800) → 負溫度: 取二補數, × -0.0625f;
else → 正溫度: × 0.0625f; 
for (i = 0; i < SG_RX_TAB_NUM * 2; i += 2)
{
    NCT7712Y_Data  = DestArray[i];
    NCT7712Y_Data <<= 8;
    NCT7712Y_Data |= DestArray[i + 1];
    NCT7712Y_Data >>= 4;

    if (NCT7712Y_Data & 0x800)
    {
        /* 負溫度補數還原 */
        NCT7712Y_Data = ~NCT7712Y_Data & 0x00000FFF;
        NCT7712Y_Data += 1;
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * -0.0625f);
    }
    else
    {
        /* 正溫度直接轉換 */
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * 0.0625f);
    }
    printf("Current Temperature = %.4f degrees Celsius.\n", NCT7712Y_Data_F);
}

7 調整呼吸速度

根據算出之溫度，直接修改共用的全域除頻變數 g_u32BreathDiv。主程式改完此值，下一次 10ms 中斷來臨時即可完成動態無痕換速。隨後回到主 loop 重新呼叫下一次閉迴路。

  • 溫度 > 27°C → g_u32BreathDiv = 5 快速呼吸 (350ms/週期)
  • 溫度 ≤ 27°C → g_u32BreathDiv = 60 慢速呼吸 (4.2s/週期)
if (NCT7712Y_Data_F > 27.0f)
{
    g_u32BreathDiv = 5;    /* 快速呼吸 (Div: 5) */
    printf("Fast breathing\n");
}
else
{
    g_u32BreathDiv = 60;   /* 慢速呼吸 (Div: 60) */
    printf("Slow breathing\n");
}
