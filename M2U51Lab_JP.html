📋 概要 M2U51 MCU Lab 設計図

M2U51 スマートキャッスル Lab

この実験では、M2U51 MCU を使用してスマートシステムを構築する方法を示します。I2C 経由で温度を読み取り、PWM 呼吸 LED の速度を変更します。環境に優しい組み込み設計のため、読み取りの間、CPU はウルトラ低消費電力モードに移行します。

コア機能

機能 説明
温度センサー 1秒ごとに I2C 経由で NCT7712Y を読み取ります (アドレス 0x48)。
呼吸 LED Timer0 PWM が PB5 LED を駆動し、デューティサイクルを 20% から 100% に変化させます。
スマートリンク 温度 > 27°C → 高速 (350ms/サイクル)、≤ 27°C → 低速 (4.2s/サイクル)。
低消費電力 待機中は NPD1 モードでスリープします。CPU 使用率は 0.1% 未満です。

周辺機器の割り当て

周辺機器 目的
Timer1 (LIRC) 自動 I2C 操作のための 1Hz トリガー。
Timer0 (LIRC) 100Hz PWM 出力 + 呼吸効果のための割り込み更新。
I2C0 センサーデータを読み取るためのマスター自動操作モード。
PDMA0 TX 用に CH0、RX 用に CH1 (スキャッターギャザー)。CPU 負荷はゼロです。
UART0 115200 ボーで温度とシステム状態をログ出力します。

💡 デザインハイライト

  • 自動 I2C 読み取り: Timer1 が I2C 自動操作をトリガー → PDMA 経由でデータが転送 → 完了時のみ CPU をウェイクアップします。
  • シームレスな呼吸効果: PWM ハードウェアは NPD1 スリープモードで動作します。CPU は 10ms ごとに 1 マイクロ秒だけウェイクアップし、g_u32BreathDiv のみを変更して次のステップをロードします。
  • ウルトラスリープ: HIRC を停止し、LIRC で動作します。出力の破損を防ぐため、スリープ前に UART をフラッシュします。
🧱 ステップ 1 クロック設定

クロック & 初期化 (SYS_Init)

1 コアシステムクロックの有効化

高速システムクロック (HCLK) を HIRC にバインドします。保護されたレジスタのロックを解除して、クロック分配値を変更します。 

/* 保護レジスタのロック解除 */
SYS_UnlockReg();

/* HIRC および LIRC クロックソースの有効化 */
CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk | CLK_PWRCTL_LIRCEN_Msk);

/* HIRC および LIRC クロックの準備完了を待機 */
CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
CLK_WaitClockReady(CLK_STATUS_LIRCSTB_Msk);

/* HCLK クロックソースを HIRC (分周比 1) に設定 */
CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_HCLKDIV_HCLK(1));

/* PCLK0/PCLK1 を HCLK/2 に設定 */
CLK->PCLKDIV = (CLK_PCLKDIV_APB0DIV_DIV2 | CLK_PCLKDIV_APB1DIV_DIV2);

/* システムコアクロックの更新 */
SystemCoreClockUpdate();

2 周辺機器クロックの割り当て

HIRC がオフのパワーダウンモードでもタイマーを動作させ続けるため、Timer0 (呼吸 LED) と Timer1 (I2C トリガーソース) を LIRC に接続します。 

/* UART0 クロックソースを HIRC (分周比 1) に設定 */
CLK_SetModuleClock(UART0_MODULE, CLK_CLKSEL2_UART0SEL_HIRC, CLK_CLKDIV_UART0(1));

/* TIMER0 クロックソースを LIRC に設定 (PWM 呼吸 LED 用、パワーダウン中も動作維持) */
CLK_SetModuleClock(TMR0_MODULE, CLK_CLKSEL1_TMR0SEL_LIRC, MODULE_NoMsk);

/* TIMER1 クロックソースを LIRC に設定 (I2C 自動操作トリガー用、パワーダウン中も動作維持) */
CLK_SetModuleClock(TMR1_MODULE, CLK_CLKSEL1_TMR1SEL_LIRC, MODULE_NoMsk);

/* 周辺機器クロックの有効化 */
CLK_EnableModuleClock(UART0_MODULE);
CLK_EnableModuleClock(I2C0_MODULE);
CLK_EnableModuleClock(TMR0_MODULE);
CLK_EnableModuleClock(TMR1_MODULE);
CLK_EnableModuleClock(PDMA0_MODULE);
CLK_EnableModuleClock(GPA_MODULE);
CLK_EnableModuleClock(GPB_MODULE);
CLK_EnableModuleClock(GPC_MODULE);

3 GPIO マッピング

UART0, I2C0, および Timer0 PWM 用の多機能ピンを設定します。ノイズ除去のため、I2C ピンのシュミットトリガを有効にします。 

/*---------------------------------------------------------------------------------------------------------*/
/* 多機能ピンの初期化                                                                                        */
/*---------------------------------------------------------------------------------------------------------*/

/* PB13 を UART0_TXD に設定 (パワーダウン中のリークを防ぐため TX のみ、RX ピンはなし) */
SYS->GPB_MFPH = (SYS->GPB_MFPH & ~SYS_GPB_MFPH_PB13MFP_Msk) | SYS_GPB_MFPH_PB13MFP_UART0_TXD;

/* PC0 を I2C0_SDA、PC1 を I2C0_SCL に設定 */
SYS->GPC_MFPL = (SYS->GPC_MFPL & ~(SYS_GPC_MFPL_PC0MFP_Msk | SYS_GPC_MFPL_PC1MFP_Msk)) |
                 (SYS_GPC_MFPL_PC0MFP_I2C0_SDA | SYS_GPC_MFPL_PC1MFP_I2C0_SCL);

/* I2C ノイズ耐性のために PC0 と PC1 のシュミットトリガを有効化 */
PC->SMTEN |= (GPIO_SMTEN_SMTEN0_Msk | GPIO_SMTEN_SMTEN1_Msk);

/* LED 呼吸効果のために PB5 を TM0 PWM 出力に設定 */
SYS->GPB_MFPL = (SYS->GPB_MFPL & ~SYS_GPB_MFPL_PB5MFP_Msk) | SYS_GPB_MFPL_PB5MFP_TM0;
🧱 ステップ 2 UART0 通信

UART0 TX と printf ロギングの有効化 (UART0_Init)

1 ロギング用ボーレート設定

デバッグメッセージを出力するために UART0 經由で printf() を使用します。周辺機器を 115200 bps でオープンします。 

void UART0_Init(void)
{
    /* UART0 のリセット */
    SYS_ResetModule(UART0_RST);

    /* UART0 の設定およびボーレートの設定 */
    UART_Open(UART0, 115200);
}

2 省電力ピン設計

ディープスリープ (NPD1 モード) 中の電流リークを避けるため、TX ピン (PB13) のみを設定し、RX は未接続またはフローティング状態にします。

🧱 ステップ 3 Timer0 PWM LED

Timer0 PWM 呼吸 LED の実装

このステップでは、Timer_PWM_Init() と TMR0_IRQHandler() を使用して、ステータスインジケータを駆動するために Timer0 を初期化します。

1 Timer0 PWM の設定

クロック & ピン要件のリマインド
• クロックソース: LIRC (38.4kHz)、初期クロック設定時にセットアップ。
• 出力ピン: PB5 (TM0)、GPB_MFPL マッピングを通じて割り当て。

1.1 Timer0 を PWM モードに切り替え、CH0 (PB5) の出力を有効にします:

/* TIMER0 を PWM モードに切り替え */
TPWM_ENABLE_PWM_MODE(TIMER0);

/* CH0 (PB5) の PWM 出力を有効化 */
TPWM_ENABLE_OUTPUT(TIMER0, TPWM_CH0);

1.2 周波数を 100Hz に設定し、初期デューティ 0% (LED オフ) から開始します:

/* 周波数 100Hz、初期デューティ 0% に設定 */
TPWM_ConfigOutputFreqAndDuty(TIMER0, 100, 0);

1.3 デューティサイクルのスケーリング用に実際の周期値を読み取ります (LIRC のドリフトを補正):

/* レジスタから実際の周期カウントを読み取り */
PWM_PERIOD_Value = TIMER0->PWMPERIOD + 1;

1.4 スリープモード (NPD1) での Timer0 クロックとデバッガの動作を設定します:

/* パワーダウンエンジンのクロックを有効化 */
TIMER0->CTL |= TIMER_CTL_PDCLKEN_Msk;

/* デバッグモード中も PWM をアクティブに維持 */
SYS_UnlockReg();
TIMER0->PWMCTL |= TIMER_PWMCTL_DBGTRIOFF_Msk;
SYS_LockReg();

1.5 10ms (100Hz) ごとに ISR をトリガーするためのアキュムレータとウェイクアップ設定を行います:

/* アキュムレータを有効化: IFACNT=0 は 1 周期ごとに実行を意味する (100Hz PWM で毎秒 100 回の ISR) */
TPWM_EnableAcc(TIMER0, 0, TPWM_IFA_PERIOD_POINT);

/* アキュムレータ割り込みを有効化 (ソフトウェア分周器が呼吸速度を制御) */
TPWM_EnableAccInt(TIMER0);
NVIC_EnableIRQ(TMR0_IRQn);

/* TMR0 ISR が NPD1 から CPU をウェイクアップして PWMCMPDAT を更新できるよう、TPWM 割り込みウェイクアップを有効化 */
TPWM_EnableWakeup(TIMER0);

2 TMR0_IRQHandler ISR (割り込みサービスルーチン)

10ms の割り込みごとに g_u32BreathCnt がインクリメントされます。それが g_u32BreathDiv に達すると、次の輝度値に移行し、スムーズなパルス出力を生成します。 

void TMR0_IRQHandler(void)
{
    /* ウェイクアップフラグのクリア (NPD1 からの復帰時に必要) */
    TPWM_ClearWakeupFlag(TIMER0);

    if (TIMER0->PWMAINTSTS & TIMER_PWMAINTSTS_IFAIF_Msk)
    {
        /* アキュムレータ割り込みフラグのクリア */
        TIMER0->PWMAINTSTS = TIMER_PWMAINTSTS_IFAIF_Msk;

        if (++g_u32BreathCnt >= g_u32BreathDiv)
        {
            g_u32BreathCnt = 0;
            TIMER0->PWMCMPDAT = SrcArray_PWM[g_u32PWMIdx];
            g_u32PWMIdx = (g_u32PWMIdx + 1) % PWM_PDMA_LENGTH;
        }
    }
}

3 デューティサイクルテーブルの初期化

main() 内で、ハードウェアの周期カウントを使用してテーブルを初期化し、ステップを生成します: 20% ↔ 40% ↔ 80% ↔ 100% ↔ 80% ↔ 40% ↔ 20%。 

/* PWM 呼吸デューティテーブルの構築: PWM 周期の 20%->40%->80%->100%->80%->40%->20% */
SrcArray_PWM[0] = PWM_PERIOD_Value * 20 / 100;
SrcArray_PWM[1] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[2] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[3] = PWM_PERIOD_Value * 100 / 100;
SrcArray_PWM[4] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[5] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[6] = PWM_PERIOD_Value * 20 / 100;
🧱 ステップ 4 I2C0 + PDMA 転送リンク

自動化された I2C 転送

自動化されたデータコンベアを設定します: Timer1 が 1Hz でオーバーフロー → ハードウェアが自動的に I2C0 をトリガー → PDMA が温度データを転送。

💡 ブロックアーキテクチャ: このリンクは3つの部分で構成されています: センサーにコマンドを書き込むための TX テーブル、受信した値を保持する RX テーブル、およびプロセスを定期的にトリガーする Timer1 の設定です。

1 TX スキャッターギャザーテーブルの構築

TX リストは、コマンド [SLV+W, レジスタアドレス, SLV+R] を I2C にロードします。最後のエントリは最初 (DMA_DESC_SC_TX[0]) に戻るようにリンクされているため、CPU の介入なしで無限にループします。 

void Build_Tx_SCTab(uint32_t u32TabNum, uint32_t u32TxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_TX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_DAR_FIX |
                                PDMA_SAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32TxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_TX[i].src    = (uint32_t)(u32StartAddr + i * u32TxSize);
        DMA_DESC_SC_TX[i].dest   = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_TX[i].offset = (uint32_t)&DMA_DESC_SC_TX[0] - SG_BASE_ADDR;
    }
}

2 RX スキャッターギャザーテーブル의構築

5 組の読み取り値 (計 10 バイト) を取得します。最後の記述子は オフセット 0 の BASIC モード に設定されます。これによりプロセスが停止し、CPU に「データの読み取りが完了しました！」と通知されます。 

void Build_Rx_SCTab(uint32_t u32TabNum, uint32_t u32RxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_RX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_SAR_FIX |
                                PDMA_DAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32RxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_RX[i].src    = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_RX[i].dest   = (uint32_t)(u32StartAddr + i * u32RxSize);
        DMA_DESC_SC_RX[i].offset = (uint32_t)&DMA_DESC_SC_RX[0] + 0x10 * (i + 1) - (PDMA0->SCATBA);
    }

    /* 最後のエントリ用: 転送完了割り込みを有効にし、ベーシックモードに切り替え */
    DMA_DESC_SC_RX[u32TabNum - 1].ctl = (DMA_DESC_SC_RX[u32TabNum - 1].ctl & ~(PDMA_DSCT_CTL_TBINTDIS_Msk | PDMA_DSCT_CTL_OPMODE_Msk)) |
                                        (PDMA_TBINTDIS_ENABLE | PDMA_OP_BASIC);
    DMA_DESC_SC_RX[u32TabNum - 1].offset = 0;
}

3 I2C 自動操作トリガーの設定

I2C 自動操作モードを Timer1 の定期的な 1Hz オーバーフローにリンクします。これにより、メインシステムをウェイクアップすることなく、バックグラウンドで完全にシリアル通信が処理されます。 

void I2C_Trigger_Init(uint32_t u32Mode, uint32_t u32Src, uint32_t u32RxCnt, uint32_t u32TxCnt)
{
    /* 自動操作モードの設定 */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_AUTOMODE_Msk) | (u32Mode);

    /* トリガーソースの選択 */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_TGSRCSEL_Msk) | (u32Src);

    I2C0->AUTOCNT = (I2C0->AUTOCNT & ~(I2C_AUTOCNT_RXCNT_Msk | I2C_AUTOCNT_TXCNT_Msk));

    if (u32RxCnt != 0)
        I2C0->AUTOCNT |= ((u32RxCnt - 1) << I2C_AUTOCNT_RXCNT_Pos);

    if (u32TxCnt != 0)
        I2C0->AUTOCNT |= ((u32TxCnt - 1) << I2C_AUTOCNT_TXCNT_Pos);

    I2C0->AUTOCTL |= I2C_AUTOCTL_TRGEN_Msk;
}
🧱 ステップ 5 低消費電力の統合

パワーダウン制御 & メインループ (AutoOperation_FunctionTest)

1 I2C バッファのフォーマット

コマンドバッファ内のターゲットアドレスとレジスタマーカーをフォーマットします:

  • SrcArray[0] = ((g_u8DeviceAddr << 1) | 0x00) (SLV + W)
  • SrcArray[1] = 0x00 (センサー温度レジスタインデックス)
  • SrcArray[2] = ((g_u8DeviceAddr << 1) | 0x01) (SLV + R)
for (i = 0; i < SG_TX_TAB_NUM; i++)
{
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x00);   /* SLV + W (0x00) */
    *pu8Tmp++ = 0x00;                              /* レジスタアドレス */
    *pu8Tmp++ = ((g_u8DeviceAddr << 1) | 0x01);   /* SLV + R (0x01) */
}

2 コールバックハンドラの割り当て

バス状態コールバックポインタを I2C_PDMA_MasterRx に向けます。 

/* マスター受信操作のための I2C0 割り込みコールバックを設定 */
s_I2C0HandlerFn = (I2C_FUNC)I2C_PDMA_MasterRx;
I2C_SET_CONTROL_REG(I2C0, I2C_CTL_AA);

3 DMA チャネルの設定

スキャッターギャザー制御リストをハードウェア転送パイプラインに直接マッピングします:

  • CH0 (TX): コマンドを継続的に転送する循環リストを実行します。
  • CH1 (RX): 5 組の読み取り値を受信します。最後の動作で BASIC モードをアサートし、完了割り込みを発生させます。
/* スレーブにデータを書き込むための PDMA CH0 スキャッターギャザーモード */
PDMA_TX_Init(I2C0_PDMA_TX_CH, SG_TX_TAB_NUM, SG_TX_LENGTH);

/* スレーブからデータを受信するための PDMA CH1 スキャッターギャザーモード */
PDMA_RX_Init(I2C0_PDMA_RX_CH, SG_RX_TAB_NUM, SG_RX_LENGTH);

4 自動操作の初期化

Timer1 の定期的なクロック出力でトリガーするように自動 I2C パラメータを設定します。 

/* TIMER1 によってトリガーされる、リピートスタート付き自動操作ランダム読み取りモード */
I2C_Trigger_Init(I2C_RANDOM_REPEAT_STA, I2C_AUTOCTL_TRIGSEL_TMR1, SG_RX_LENGTH, SG_TX_LENGTH);

5 ディープスリープモード (NPD1) の設定

コアクロックを停止するために CLK_PowerDown() を呼び出します。CPU は周辺機器の処理を待つ間スリープします。

NPD1 スリープの仕組み:
  • HIRC が停止 → CPU、PDMA、および UART がサスペンドします。電流消費が大幅に低下します。
  • LIRC がアクティブ → Timer0 が PWM LED をパルス駆動し、Timer1 が定期的にカウントします。
  • ★ ウェイクアップ 1: Timer0 アキュムレータ (10ms ごと):
    • CPU が短時間ウェイクアップして TMR0_IRQHandler を実行し、LED の輝度を更新します。
    • PDMA_DONE をチェックします。まだ 0 であるため、CPU はすぐにスリープに戻ります。
  • ★ ウェイクアップ 2: Timer1 タイムアウト (1秒ごと):
    • Timer1 がオーバーフローし、I2C 自動操作を直接開始します。CPU はスリープ状態を維持します。
    • バス処理が完了します: START → SLA+W → REG → Repeat START → SLA+R → READ → STOP。
    • PDMA が読み取ったデータをメモリに移動します。
    • 最後の読み取りが割り込みをトリガーします。PDMA0_IRQHandler を実行し、PDMA_DONE = 1 に設定して、CPU を完全にウェイクアップさせてデータを処理します。
SYS_UnlockReg();
CLK_SetPowerDownMode(CLK_PMUCTL_PDMSEL_NPD1);
CLK->PMUCTL = (CLK->PMUCTL & ~(CLK_PMUCTL_PDLDCSEL_Msk)) | CLK_PMUCTL_PDLDCSEL_ULP;

while (!PDMA_DONE)
{
    /* ウェイクアップフラグのクリア */
    CLK->PMUSTS |= CLK_PMUSTS_CLRWK_Msk;

    /* UART 破損の防止 */
    UART_WAIT_TX_EMPTY(UART0);

    /* CPU & HIRC はここでサスペンドされます */
    CLK_PowerDown();
}
SYS_LockReg();

6 温度読み取り値のパース

取得した 5 組の読み取り値 (各 2 バイト、MSB および LSB) をデコードします:

raw = (DestArray[i] << 8 | DestArray[i+1]) >> 4; (12ビット)
if (raw & 0x800) → 負の値: 2の補数 × -0.0625f;
else → 正の値: × 0.0625f; 
for (i = 0; i < SG_RX_TAB_NUM * 2; i += 2)
{
    NCT7712Y_Data  = DestArray[i];
    NCT7712Y_Data <<= 8;
    NCT7712Y_Data |= DestArray[i + 1];
    NCT7712Y_Data >>= 4;

    if (NCT7712Y_Data & 0x800)
    {
        /* 負の温度変換 */
        NCT7712Y_Data = ~NCT7712Y_Data & 0x00000FFF;
        NCT7712Y_Data += 1;
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * -0.0625f);
    }
    else
    {
        /* 正の温度変換 */
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * 0.0625f);
    }
    printf("Current Temperature = %.4f degrees Celsius.\n", NCT7712Y_Data_F);
}

7 呼吸速度の変更

温度に基づいてグローバルソフトウェア分周変数 g_u32BreathDiv を変更します。次の 10ms 割り込みで即座に適用され、シームレスに移行します。

  • 温度 > 27°C → g_u32BreathDiv = 5 (高速呼吸: 350ms/サイクル)
  • 温度 ≤ 27°C → g_u32BreathDiv = 60 (低速呼吸: 4.2s/サイクル)
if (NCT7712Y_Data_F > 27.0f)
{
    g_u32BreathDiv = 5;    /* 高速 (分周比: 5) */
    printf("Fast breathing\n");
}
else
{
    g_u32BreathDiv = 60;   /* 低速 (分周比: 60) */
    printf("Slow breathing\n");
}
