📋 Overview M2U51 MCU Lab Blueprint

M2U51 Smart Castle Lab

This lab shows how to build a smart system with the M2U51 MCU. It reads temperature via I2C and changes the PWM Breathing LED speed. The CPU enters ultra-low power mode between readings for green embedded design.

Core Features

Feature Description
Temp Sensor Reads NCT7712Y via I2C every second (address 0x48).
Breathing LED Timer0 PWM drives PB5 LED, shifting duty cycle from 20% to 100%.
Smart Link Temp > 27°C → fast speed (350ms/cycle); ≤ 27°C → slow speed (4.2s/cycle).
Low Power Sleeps in NPD1 mode while waiting. CPU usage < 0.1%.

Peripheral Allocation

Peripheral Purpose
Timer1 (LIRC) 1Hz trigger for auto I2C operations.
Timer0 (LIRC) 100Hz PWM output + interrupt updates for breathing effect.
I2C0 Master Auto-Operation mode for reading sensor data.
PDMA0 CH0 for TX, CH1 for RX (scatter-gather). Zero CPU load.
UART0 Logs temperature and system state at 115200 baud.

💡 Design Highlights

  • Auto I2C Read: Timer1 triggers I2C Auto-Op → data is moved via PDMA → wakes CPU only when done.
  • Seamless Breathing: PWM hardware runs in NPD1 sleep mode. CPU wakes for a microsecond every 10ms to load the next step by changing only g_u32BreathDiv.
  • Ultra Sleep: Stops HIRC and runs on LIRC. Flushes UART before sleep to prevent output corruption.
🧱 Step 1 Clock Configuration

Clock & Initialization (SYS_Init)

1 Enable Core System Clocks

We bind the high-speed system clock (HCLK) to HIRC. We unlock protected registers to modify clock distribution values. 

/* Unlock protected registers */
SYS_UnlockReg();

/* Enable HIRC and LIRC clock sources */
CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk | CLK_PWRCTL_LIRCEN_Msk);

/* Wait for HIRC and LIRC clock ready */
CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
CLK_WaitClockReady(CLK_STATUS_LIRCSTB_Msk);

/* Set HCLK clock source to HIRC with divider 1 */
CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_HCLKDIV_HCLK(1));

/* Set PCLK0/PCLK1 to HCLK/2 */
CLK->PCLKDIV = (CLK_PCLKDIV_APB0DIV_DIV2 | CLK_PCLKDIV_APB1DIV_DIV2);

/* Update System Core Clock */
SystemCoreClockUpdate();

2 Assign Peripheral Clocks

To keep our timers running in Power-Down mode when HIRC is turned off, we connect Timer0 (Breathing LED) and Timer1 (I2C trigger source) to LIRC. 

/* Select UART0 clock source as HIRC with divider 1 */
CLK_SetModuleClock(UART0_MODULE, CLK_CLKSEL2_UART0SEL_HIRC, CLK_CLKDIV_UART0(1));

/* Select TIMER0 clock source as LIRC (for PWM breathing LED, keeps running in power-down) */
CLK_SetModuleClock(TMR0_MODULE, CLK_CLKSEL1_TMR0SEL_LIRC, MODULE_NoMsk);

/* Select TIMER1 clock source as LIRC (for I2C auto-operation trigger, keeps running in power-down) */
CLK_SetModuleClock(TMR1_MODULE, CLK_CLKSEL1_TMR1SEL_LIRC, MODULE_NoMsk);

/* Enable peripheral clocks */
CLK_EnableModuleClock(UART0_MODULE);
CLK_EnableModuleClock(I2C0_MODULE);
CLK_EnableModuleClock(TMR0_MODULE);
CLK_EnableModuleClock(TMR1_MODULE);
CLK_EnableModuleClock(PDMA0_MODULE);
CLK_EnableModuleClock(GPA_MODULE);
CLK_EnableModuleClock(GPB_MODULE);
CLK_EnableModuleClock(GPC_MODULE);

Configure multi-function pins for UART0, I2C0, and Timer0 PWM. Schmitt triggers are enabled on I2C pins for noise rejection.

🧱 Step 3 Timer0 PWM LED

Implement Timer0 PWM Breathing LED

This step initializes Timer0 to drive our status indicator using Timer_PWM_Init() and TMR0_IRQHandler():

1 Configure Timer0 PWM

Clock & Pin Requirement Reminder
• Clock Source: LIRC (38.4kHz), set up during initial clock settings.
• Output Pin: PB5 (TM0), assigned through GPB_MFPL mapping.

1.1 Switch Timer0 to PWM mode and enable output on CH0 (PB5):

/* Switch TIMER0 to PWM mode */
TPWM_ENABLE_PWM_MODE(TIMER0);

/* Enable PWM output on CH0 (PB5) */
TPWM_ENABLE_OUTPUT(TIMER0, TPWM_CH0);

1.2 Set frequency to 100Hz, starting with 0% duty (LED off):

/* Set frequency 100Hz, 0% initial duty */
TPWM_ConfigOutputFreqAndDuty(TIMER0, 100, 0);

1.3 Read period value for duty cycle scaling (compensates for LIRC drift):

/* Read actual period count from register */
PWM_PERIOD_Value = TIMER0->PWMPERIOD + 1;

1.4 Enable Timer0 clock in sleep mode (NPD1) and debugger behavior:

/* Enable Power-down engine clock */
TIMER0->CTL |= TIMER_CTL_PDCLKEN_Msk;

/* Keep PWM active in debug mode */
SYS_UnlockReg();
TIMER0->PWMCTL |= TIMER_PWMCTL_DBGTRIOFF_Msk;
SYS_LockReg();

1.5 Configure accumulator and wakeup settings to trigger the ISR every 10ms (100Hz):

/* Enable accumulator: IFACNT=0 means fire every 1 period (100 ISR/sec at 100Hz PWM) */
TPWM_EnableAcc(TIMER0, 0, TPWM_IFA_PERIOD_POINT);

/* Enable accumulator interrupt (software divider controls breathing speed) */
TPWM_EnableAccInt(TIMER0);
NVIC_EnableIRQ(TMR0_IRQn);

/* Enable TPWM interrupt wake-up so TMR0 ISR can wake CPU from NPD1 to update PWMCMPDAT */
TPWM_EnableWakeup(TIMER0);

2 TMR0_IRQHandler ISR

Each 10ms interrupt increments g_u32BreathCnt. Once it reaches g_u32BreathDiv, it moves to the next brightness value to output smooth pulsing. 

void TMR0_IRQHandler(void)
{
    /* Clear wakeup flag (needed when waking from NPD1) */
    TPWM_ClearWakeupFlag(TIMER0);

    if (TIMER0->PWMAINTSTS & TIMER_PWMAINTSTS_IFAIF_Msk)
    {
        /* Clear accumulator interrupt flag */
        TIMER0->PWMAINTSTS = TIMER_PWMAINTSTS_IFAIF_Msk;

        if (++g_u32BreathCnt >= g_u32BreathDiv)
        {
            g_u32BreathCnt = 0;
            TIMER0->PWMCMPDAT = SrcArray_PWM[g_u32PWMIdx];
            g_u32PWMIdx = (g_u32PWMIdx + 1) % PWM_PDMA_LENGTH;
        }
    }
}

3 Initialize Duty Cycle Table

Inside main(), initialize the table using the hardware period count to generate steps: 20% ↔ 40% ↔ 80% ↔ 100% ↔ 80% ↔ 40% ↔ 20%. 

/* Build PWM breathing duty table: 20%->40%->80%->100%->80%->40%->20% of PWM period */
SrcArray_PWM[0] = PWM_PERIOD_Value * 20 / 100;
SrcArray_PWM[1] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[2] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[3] = PWM_PERIOD_Value * 100 / 100;
SrcArray_PWM[4] = PWM_PERIOD_Value * 80 / 100;
SrcArray_PWM[5] = PWM_PERIOD_Value * 40 / 100;
SrcArray_PWM[6] = PWM_PERIOD_Value * 20 / 100;
🧱 Step 4 I2C0 + PDMA Transfer Link

Automated I2C Transfer

We configure an automated data conveyor: Timer1 overflows at 1Hz → hardware automatically triggers I2C0 → PDMA transfers temperature data.

💡 Block Architecture: This link consists of three parts: We construct a TX Table to write commands to the sensor, an RX Table to hold received values, and configure Timer1 to trigger the process periodically.

1 Build TX Scatter-Gather Table

The TX list loads the command [SLV+W, Reg Addr, SLV+R] into I2C. The final entry links back to the beginning (DMA_DESC_SC_TX[0]) so it loops infinitely without CPU intervention. 

void Build_Tx_SCTab(uint32_t u32TabNum, uint32_t u32TxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_TX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_DAR_FIX |
                                PDMA_SAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32TxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_TX[i].src    = (uint32_t)(u32StartAddr + i * u32TxSize);
        DMA_DESC_SC_TX[i].dest   = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_TX[i].offset = (uint32_t)&DMA_DESC_SC_TX[0] - SG_BASE_ADDR;
    }
}

2 Build RX Scatter-Gather Table

We fetch 5 sets of readings (10 bytes total). The last descriptor is configured to BASIC mode with offset 0. This stops the process and alerts the CPU: "Data reading completed!" 

void Build_Rx_SCTab(uint32_t u32TabNum, uint32_t u32RxSize, uint32_t u32StartAddr)
{
    uint32_t i;

    for (i = 0; i < u32TabNum; i++)
    {
        DMA_DESC_SC_RX[i].ctl = PDMA_OP_SCATTER |
                                PDMA_REQ_SINGLE |
                                PDMA_SAR_FIX |
                                PDMA_DAR_INC |
                                PDMA_WIDTH_8 |
                                PDMA_TBINTDIS_DISABLE |
                                ((u32RxSize - 1) << PDMA_DSCT_CTL_TXCNT_Pos);
        DMA_DESC_SC_RX[i].src    = (uint32_t)&(I2C0->DAT);
        DMA_DESC_SC_RX[i].dest   = (uint32_t)(u32StartAddr + i * u32RxSize);
        DMA_DESC_SC_RX[i].offset = (uint32_t)&DMA_DESC_SC_RX[0] + 0x10 * (i + 1) - (PDMA0->SCATBA);
    }

    /* For the last entry: enable transfer-done interrupt and switch to basic mode */
    DMA_DESC_SC_RX[u32TabNum - 1].ctl = (DMA_DESC_SC_RX[u32TabNum - 1].ctl & ~(PDMA_DSCT_CTL_TBINTDIS_Msk | PDMA_DSCT_CTL_OPMODE_Msk)) |
                                        (PDMA_TBINTDIS_ENABLE | PDMA_OP_BASIC);
    DMA_DESC_SC_RX[u32TabNum - 1].offset = 0;
}

3 Configure I2C Auto-Operation Trigger

Link I2C Auto-Op mode to the periodic 1Hz overflows of Timer1. This handles the serial exchange completely in the background without waking the main system. 

void I2C_Trigger_Init(uint32_t u32Mode, uint32_t u32Src, uint32_t u32RxCnt, uint32_t u32TxCnt)
{
    /* Set Auto-operation Mode */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_AUTOMODE_Msk) | (u32Mode);

    /* Trigger source select */
    I2C0->AUTOCTL = (I2C0->AUTOCTL & ~I2C_AUTOCTL_TGSRCSEL_Msk) | (u32Src);

    I2C0->AUTOCNT = (I2C0->AUTOCNT & ~(I2C_AUTOCNT_RXCNT_Msk | I2C_AUTOCNT_TXCNT_Msk));

    if (u32RxCnt != 0)
        I2C0->AUTOCNT |= ((u32RxCnt - 1) << I2C_AUTOCNT_RXCNT_Pos);

    if (u32TxCnt != 0)
        I2C0->AUTOCNT |= ((u32TxCnt - 1) << I2C_AUTOCNT_TXCNT_Pos);

    I2C0->AUTOCTL |= I2C_AUTOCTL_TRGEN_Msk;
}

5 Configure Deep Sleep Mode (NPD1)

Call CLK_PowerDown() to halt core clocks. The CPU goes to sleep while waiting for peripheral transactions.

How NPD1 Sleep Works:
  • HIRC is Halted → CPU, PDMA, and UART suspend. Current consumption drops significantly.
  • LIRC is Active → Timer0 pulses the PWM LED, and Timer1 counts periodically.
  • ★ Wakeup 1: Timer0 Accumulator (Every 10ms):
    • CPU wakes briefly to run TMR0_IRQHandler and update LED brightness.
    • Checks PDMA_DONE. Since it is still 0, the CPU returns to sleep immediately.
  • ★ Wakeup 2: Timer1 Timeout (Every 1s):
    • Timer1 overflows and starts I2C Auto-Operation directly. CPU remains asleep.
    • Bus transaction completes: START → SLA+W → REG → Repeat START → SLA+R → READ → STOP.
    • PDMA moves read data into memory.
    • The last read triggers an interrupt. It runs PDMA0_IRQHandler, sets PDMA_DONE = 1, and wakes the CPU fully to process data.
SYS_UnlockReg();
CLK_SetPowerDownMode(CLK_PMUCTL_PDMSEL_NPD1);
CLK->PMUCTL = (CLK->PMUCTL & ~(CLK_PMUCTL_PDLDCSEL_Msk)) | CLK_PMUCTL_PDLDCSEL_ULP;

while (!PDMA_DONE)
{
    /* Clear wakeup flag */
    CLK->PMUSTS |= CLK_PMUSTS_CLRWK_Msk;

    /* Prevent UART corruption */
    UART_WAIT_TX_EMPTY(UART0);

    /* CPU & HIRC suspended here */
    CLK_PowerDown();
}
SYS_LockReg();

6 Parse Temperature Readings

Decode the 5 fetched readings (2 bytes each, MSB and LSB):

raw = (DestArray[i] << 8 | DestArray[i+1]) >> 4; (12-bit)
if (raw & 0x800) → Negative: Two's complement × -0.0625f;
else → Positive: × 0.0625f; 
for (i = 0; i < SG_RX_TAB_NUM * 2; i += 2)
{
    NCT7712Y_Data  = DestArray[i];
    NCT7712Y_Data <<= 8;
    NCT7712Y_Data |= DestArray[i + 1];
    NCT7712Y_Data >>= 4;

    if (NCT7712Y_Data & 0x800)
    {
        /* Negative conversion */
        NCT7712Y_Data = ~NCT7712Y_Data & 0x00000FFF;
        NCT7712Y_Data += 1;
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * -0.0625f);
    }
    else
    {
        /* Positive conversion */
        NCT7712Y_Data_F = (float)(NCT7712Y_Data * 0.0625f);
    }
    printf("Current Temperature = %.4f degrees Celsius.\n", NCT7712Y_Data_F);
}

7 Modify Breathing Speed

We modify the global software divider variable g_u32BreathDiv based on temperature. The next 10ms interrupt applies it instantly for seamless transitions.

  • Temp > 27°C → g_u32BreathDiv = 5 (Fast breathing: 350ms/cycle)
  • Temp ≤ 27°C → g_u32BreathDiv = 60 (Slow breathing: 4.2s/cycle)
if (NCT7712Y_Data_F > 27.0f)
{
    g_u32BreathDiv = 5;    /* Fast (Div: 5) */
    printf("Fast breathing\n");
}
else
{
    g_u32BreathDiv = 60;   /* Slow (Div: 60) */
    printf("Slow breathing\n");
}
